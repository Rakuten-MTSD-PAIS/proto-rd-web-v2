## Variable Scoping Summary

| Scope | Token Groups |
|---|---|
| `CORNER_RADIUS` | All `radius-*` tokens |
| `GAP` | All `paddings/p-*`, `space/*`, component spacing |
| `WIDTH_HEIGHT` | All `hight/*`, `containers/@*` |
| `FONT_SIZE` | All `typography v2/*/size` |
| `LINE_HEIGHT` | All `typography v2/*/line-height` |
| `LETTER_SPACING` | All `typography v2/*/tracking`, `text/tracking-*` |
| `ALL_FILLS` | All `COLOR` type variables |
